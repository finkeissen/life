# Dramaturgy Layer

## Purpose

This directory contains the macro- and micro-dramaturgical structures derived from the formal architecture of the project.

The dramaturgy layer does not invent plot independently.  
Its function is to translate architectural structures into narrative dynamics.

It therefore stands between:

- architectural framework
- narrative projection
- concrete execution

In this sense, dramaturgy is not a secondary creative layer, but a **derived structural layer**.


---

# Core Principle

No plot invention without architectural reference.

Every dramaturgical element must be traceable to:

- the core architecture
- the epistemic trajectory
- the zone model
- the recurrence logic
- the structural tensions already defined elsewhere in the project

Dramaturgy is therefore constrained, not free-floating.


---

# Function of the Dramaturgy Layer

The purpose of this layer is to define how structural tensions become narratively perceptible.

It does not answer:

- what exactly happens in the story
- which concrete scenes must be written
- how characters are individualized in execution

Instead, it answers:

- how structural movement is organized
- how epistemic tension grows
- where recurrence becomes visible
- how conflict escalates
- how insight changes narrative form


---

# Expected Outputs

The dramaturgy layer should generate the following structural outputs:

- macro structure
- zone progression
- tension curve
- recurrence checkpoints
- structural escalation map

These outputs define the dramatic grammar from which later scenes, chapters, acts, or sequences may be derived.


---

# Dramaturgical Orientation

This project does not primarily use classical plot dramaturgy.

Its primary orientation is **epistemic dramaturgy**.

That means:

- tension arises from instability of understanding
- conflict emerges when insight threatens structural coherence
- revelation occurs through patterns, not exposition alone
- recurrence is more important than surprise
- structural recognition is more important than event novelty

The underlying dramatic movement is therefore not:

exposition → action → climax → resolution

but rather:

immersion → fracture → pattern recognition → conflict → insight → isolation → reconfiguration


---

# Scope

This layer may apply across multiple projections, including:

- novel
- libretto
- essayistic narrative forms
- filmic or hybrid forms

It defines a transferable dramaturgical logic rather than a medium-specific script format.


---

# Relationship to Other Layers

The dramaturgy layer depends on the existing architectural documents.

In particular, it should remain compatible with:

- the virtual timeline
- the structural mirror logic
- the epoch projection logic
- the zone model
- the recurrence architecture

It is therefore a mediating layer between structural abstraction and narrative realization.


---

# Constraints

The dramaturgy layer must avoid:

- autonomous plot invention
- arbitrary emotional escalation
- character decisions without structural basis
- decorative complexity without epistemic function

Every dramatic intensification must correspond to a structural intensification.


---

# Working Rule

A dramatic element is valid only if it can answer the question:

What structural tension, epistemic shift, recurrence pattern, or escalation dynamic does this element make visible?


---

# Summary

The dramaturgy layer transforms architecture into perceivable form.

It does not create stories by improvisation.  
It creates the structural conditions under which stories may emerge without betraying the architecture.
