# Storyboard

## Purpose

This directory contains the structural storyboard for the novel projection.

The storyboard does not define literary scenes, dialogue, or stylistic decisions.
Its purpose is to test whether the architectural elements of the project can generate a coherent narrative movement.

The storyboard operates at the level of **structural scenes**.

Each scene should clarify:

- which phase of the virtual timeline it belongs to
- which structural tension becomes visible
- how it mirrors or recurs in other epochs
- what epistemic shift occurs

The storyboard therefore functions as a **narrative architecture test**, not as a finished outline.

## Structural Basis

The storyboard derives from:

- virtual timeline
- structural tension matrix
- structural mirror logic
- dramaturgy layer
