# Montage and Recurrence

## Purpose

This document defines how recurrence becomes visible through editing.

Montage should not primarily accelerate plot.
Its main function is to reveal structural similarity across contexts.

## Core Functions

### Recurrence with Variation

A later image recalls an earlier one while shifting its meaning.

### Cross-Epoch Mirroring

Different periods are linked through analogous situations, gestures, or institutional forms.

### Retrospective Reinterpretation

A new montage relation changes the meaning of a previous image.

### Escalation by Pattern Density

Interpretive pressure grows because the audience sees the same structure recur more often.

## Constraint

Montage should avoid explanatory overstatement.
Recognition should emerge before verbal articulation whenever possible.
