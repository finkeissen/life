# Visual Grammar

## Purpose

This document defines the visual grammar through which structural dynamics become perceptible.

Images should not merely illustrate events.
They should reveal relations between:

- bodies
- spaces
- institutions
- routines
- thresholds
- repetitions

## Core Visual Functions

### Spatial Coherence

Images establish environments as locally coherent orders.

Typical means:

- repeated framing of routines
- architectural symmetry
- procedural movement
- stable interior logic

### Fracture

Images reveal inconsistencies within stable orders.

Typical means:

- visual interruption
- asymmetry
- misaligned action
- detail that resists the dominant interpretation

### Pattern Recognition

Images repeat with variation.

Typical means:

- same corridor, different epoch
- same gesture, different institution
- same waiting posture, different context

### Structural Pressure

The frame should reveal how environments constrain action.

Typical means:

- blocked movement
- depth layering
- crowding
- administrative spaces
- ritualized positioning

## Constraint

The visual system should avoid decorative symbolism.
Repetition must remain structurally motivated.
