# Time-Image Strategy

## Purpose

This document defines how time operates in the film projection.

Time should not function only as chronological progression.
It should also function as a field in which structurally similar situations become legible across distance.

## Modes of Time

### Chronological Time

Used sparingly to maintain basic orientation.

### Layered Time

Different periods appear in proximity without full linear explanation.

### Recalled Time

Later sequences reorganize earlier ones.

### Structural Time

Different events are linked because they belong to the same epistemic movement.

## Working Rule

Temporal transitions should increase structural clarity rather than merely create mystery.

## Constraint

Temporal fragmentation must remain readable at the level of structural function even when chronology is unstable.
