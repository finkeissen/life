# Source Map — life

This file documents where the elements of the core originate.

The framework did not emerge in a single step.
It is a consolidation of earlier work, including books, notes, and previous repositories.

The purpose of this map is to make those sources explicit.

This prevents the core from relying on implicit knowledge
that exists only in the author's memory.

---

## Structure

Each entry follows this format:

Source → Core Component → Status

Status categories:

- integrated
- partially integrated
- background
- not yet extracted

---

## Example Entries

Book A → invariants → integrated  
Book B → responsibility model → partially integrated  
Notes Archive → decision structures → background  
Old Repository X → development model → not yet extracted

---

## Interpretation of Status

**Integrated**

The relevant ideas have been fully translated into the current framework.

**Partially Integrated**

Some elements have been incorporated,
but the original material may still contain structures
that are not yet represented in the core.

**Background**

The source influenced the thinking,
but its material is not directly structured into the core.

**Not Yet Extracted**

Relevant ideas exist in the source,
but they have not yet been translated into the framework.

---

## Guiding Principle

The purpose of the source map is not archival completeness.

Its purpose is structural clarity:

Which upstream work actually feeds the core.
