# Projection Matrix

| Core Element | Novel | Libretto | Film |
|-------------|-------|----------|------|
| Virtual Timeline | narrative phases | operatic acts / opera cycle | sequence architecture |
| Structural Tension | internal and social conflict | voice, chorus, orchestral tension | bodies, space, montage, atmosphere |
| Structural Mirror | mirrored scenes across epochs | leitmotif and scene mirroring | cross-cutting, repeated framing, visual recurrence |
| Recurrence Engine | repeated narrative situations | musical and dramatic recurrence | montage recurrence and image variation |
| Insight | reinterpretation in narration | aria / ensemble / rupture | retrospective image relation, silence, changed framing |
| Institution | narrative environment | chorus and role structure | architecture, procedure, ambient sound, blocking |

## Function

This matrix clarifies how the same architectural elements are instantiated differently across media.
